# Public Assets

Static media served from `public/assets/` (referenced as absolute paths, e.g. `/assets/demo-video.mp4`).

## Intended production assets

| File | Purpose |
|------|---------|
| `hero-ramp.webp` | Hero image (recommended ~1920x1080). Currently a placeholder SVG — replace it. |
| `demo-video.mp4` | 15-30s product demo for the "Watch It In Action" section. Currently a placeholder poster — replace it. |
| `badges/*` | Trust/certification badges (SVG or PNG), e.g. `paw-safety-certified.svg`. |

## Placeholders

- `hero-placeholder.svg` — temporary stand-in for `hero-ramp.webp`
- `poster-placeholder.svg` — temporary stand-in for the `demo-video.mp4` poster

Remove the placeholders once your real files are in place.
